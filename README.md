# Cyber Snake

## Описание

Учебный проект по основам Go. Интерактивная игра змейка в терминале. Игрок управляет головой змейки и собирает еду для удлинения. Уровень повышается после каждых пяти съеденых элементов и новый вирус добавляется на арену. Игра заканчивается при столкновении с вирусами, с границей арены или собственным хвостом.   

Управление:
- Стрелки/WASD - движение змейки
- Esc/Q - выход
- R - перезапуск

## Установка и запуск

```bash
go run ./main.go
```
